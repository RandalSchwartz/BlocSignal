# Support & Community Resources

Thank you for building with `BlocSignal`! This document guides you to the best channels for asking questions, getting help, and engaging with the community.

---

## 💬 Where to Get Help

### 1. GitHub Discussions
For general questions, architectural advice, design pattern discussions, and sharing ideas:
* Visit [GitHub Discussions](https://github.com/RandalSchwartz/BlocSignal/discussions) on this repository.
* Browse existing answers or start a new discussion under **Q&A** or **General**.

### 2. GitHub Issues
For reproducible bugs, documentation errors, or concrete feature proposals:
* Search existing [GitHub Issues](https://github.com/RandalSchwartz/BlocSignal/issues) to verify if the issue was previously reported.
* Open a new issue using our structured issue templates (for example **Bug Report**, **Feature Request**, or **Docs Improvement**).

### 3. Community Channels
Connect with other Dart and Flutter engineers:
* **Discord**: Active discussions in the Flutter and Dart community Discord servers.
* **Reddit**: Post questions or show your projects in [r/FlutterDev](https://www.reddit.com/r/FlutterDev/) or [r/dartlang](https://www.reddit.com/r/dartlang/).
* **Stack Overflow**: Tag questions with `flutter` and `dart` (and mention `bloc_signals`).
